# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a major cloud computing platform launched in 2010. It is known for its strong integration with Microsoft's existing enterprise software ecosystem, including Windows Server, Active Directory, and Microsoft 365, making it a common choice for businesses already using Microsoft products.

## Global Infrastructure
Azure's global infrastructure spans over 70 datacenter regions across 33 countries, more than any other cloud provider. Regions are grouped into geographies to meet specific data residency and compliance requirements, and many regions offer Availability Zones—physically separate datacenters with independent power, cooling, and networking for added resiliency.

## Cloud Management Console
Azure provides the **Azure Portal**, a web-based, unified management interface for creating, configuring, and monitoring Azure resources.

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand, scalable computing resources
2. **Azure Blob Storage** – Object storage for unstructured data
3. **Azure SQL Database** – Managed relational database service
4. **Azure Active Directory (Microsoft Entra ID)** – Identity and access management

## Three (3) Advantages
1. Seamless integration with Microsoft products (Windows Server, Microsoft 365, Active Directory)
2. Largest global datacenter footprint among cloud providers, supporting data residency needs
3. Strong hybrid cloud capabilities for organizations transitioning from on-premises infrastructure

## Typical Enterprise Use Cases
- Organizations already using Microsoft products (Windows Server, Microsoft 365) migrating to the cloud
- Enterprises needing hybrid cloud solutions that combine on-premises and cloud infrastructure
- Businesses with strict data residency or compliance requirements
