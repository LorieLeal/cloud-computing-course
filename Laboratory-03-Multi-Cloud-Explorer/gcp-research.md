# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing offering, built on the same infrastructure that powers Google Search, YouTube, and Gmail. GCP is especially known for its strengths in data analytics, artificial intelligence, and machine learning, as well as its Kubernetes leadership since Google originally created Kubernetes.

## Global Infrastructure
GCP operates across 43 global regions and 130+ zones, connected by Google's global network spanning over 200 countries and territories with more than 7.75 million kilometers of terrestrial and subsea fiber. Each region is an independent geographic area made up of multiple isolated zones, allowing workloads to be distributed for high availability and fault tolerance.

## Cloud Management Console
GCP provides the **Google Cloud Console**, a web-based interface for managing, monitoring, and configuring all Google Cloud resources and services.

## Four (4) Core Services
1. **Compute Engine** – Scalable virtual machines
2. **Cloud Storage** – Object storage for any amount of data
3. **Cloud SQL** – Managed relational database service
4. **Identity and Access Management (IAM)** – Controls access to Google Cloud resources

## Three (3) Advantages
1. Strong leadership in AI/ML tools and data analytics (e.g., BigQuery, Vertex AI)
2. Creator and leading provider of Kubernetes (Google Kubernetes Engine)
3. Competitive pricing and strong network performance backed by Google's global fiber network

## Typical Enterprise Use Cases
- Companies developing AI/ML applications requiring high-performance computing
- Organizations relying heavily on data analytics and big data processing
- Businesses deploying containerized applications using Kubernetes
