# AWS (Amazon Web Services) Research

## Brief Overview
Amazon Web Services (AWS) is the world's most comprehensive and broadly adopted cloud platform, launched in 2006. It offers hundreds of services covering compute, storage, databases, networking, machine learning, and artificial intelligence, and is widely regarded as the market leader in cloud computing.

## Global Infrastructure
AWS operates across more than 36 geographic regions and 114+ Availability Zones (AZs) worldwide. Each region consists of at least three isolated AZs, and each AZ has its own independent power, cooling, and physical security, connected through high-bandwidth, low-latency networking. This design allows applications to remain highly available even if one facility experiences an outage.

## Cloud Management Console
AWS provides the **AWS Management Console**, a web-based interface that allows users to access, configure, and monitor all AWS services from a single dashboard.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Virtual servers for running applications
2. **Amazon S3 (Simple Storage Service)** – Scalable object storage
3. **Amazon RDS (Relational Database Service)** – Managed relational databases
4. **AWS IAM (Identity and Access Management)** – Controls user access and permissions

## Three (3) Advantages
1. Widest range of services and most mature ecosystem among cloud providers
2. Largest global infrastructure footprint, enabling low-latency deployment worldwide
3. Strong scalability and reliability suited for enterprise-level workloads

## Typical Enterprise Use Cases
- Startups needing to scale infrastructure quickly without large upfront investment
- Large e-commerce platforms requiring high availability and global reach
- Companies building AI/ML applications that need high-performance computing resources
